# SEG FAYAT — V25.2 — sélection et téléchargement des médias

Base : V25.1 (visionneuse plein écran).

- Coches de sélection sur les photos des Archives terrain et du reportage complet.
- Sélection de toutes les photos d’un reportage ou de toutes les dates.
- Sélection et téléchargement de la photo ouverte en plein écran.
- Téléchargement en fichier unique pour une photo ; archive ZIP pour plusieurs photos, structurée par date.
- ZIP produit dans le navigateur sans serveur ni dépendance externe, à partir des médias WebP effectivement publiés.
- Les photos originales (JPEG/HEIC) des archives d’entrée ne sont pas incluses dans les exports web.
- Pour de grandes sélections sur mobile, prévoir assez de mémoire disponible ; l’export se prépare localement dans le navigateur.
