# SEG FAYAT — V25

Base : V24, conservée intégralement. Ajout de 43 clichés de septembre 2026 issus des 5 archives fournies, classés en 10 reportages par date de prise de vue. Images WebP optimisées à 2200 pixels maximum et miniatures WebP à 620 pixels maximum. Les JPG originaux restent dans les archives sources et ne sont pas ré-embarqués.

Pour publier : déposer le contenu de ce dossier à la racine de GitHub Pages. Les JSON sont chargés via HTTP ; en local utiliser `python -m http.server 8080`.

Les 7 panoramas 360° historiques et la frise de comparaison de la V24 sont conservés. Aucun nouveau fichier JPG n’a été présumé panoramique sans vérification.
